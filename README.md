# WorkPulse

> **AI-Enhanced Organizational Workflow, Request, and Activity Management Platform**

WorkPulse is a configuration-driven, multi-tenant enterprise workflow management platform equipped with a secure, RBAC-governed **Pulse AI Copilot**, automated SLA escalation engine, and universal approval governance gates.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
npm --prefix backend install
npm --prefix frontend install
```

### 2. Start Both Backend and Frontend
```bash
npm run dev
```

- **Backend API**: `http://localhost:5000`
- **Frontend App**: `http://localhost:3000`

---
